## Project Structure

- **`backend/`**: Backend service (Go-based with database migrations and API endpoints).
- **`frontend/`**: Frontend web application (Next.js, TypeScript, Tailwind CSS).

## Getting Started

### Prerequisites

- Node.js & npm (for the frontend)
- Go (for the backend)
